RunLab · Test collegamento Garmin

Questo test non richiede la tua chiave Garmin e non accede ai tuoi allenamenti. Controlla se il browser permette di leggere una risposta dell'API Garmin da GitHub Pages.

In attesa del test.
Il test invia una credenziale volutamente non valida. Se il server consente l'accesso dal browser, potremo leggere un codice HTTP di errore (per esempio 401). Un errore di rete/CORS non prova da solo che il server blocchi CORS: può avere anche altre cause.
